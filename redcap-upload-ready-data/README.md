# REDCap Upload Ready Data

This directory contains JSON files with REDCap status updates generated by the data processor.

## File Naming Convention

Files are named using the pattern: `NACC_UPLOAD_{DDMMYYYY}_{HHMMSS}_status.json`

Where:
- `DDMMYYYY` = Date in DD/MM/YYYY format  
- `HHMMSS` = Time in HH:MM:SS format

## File Structure

Each JSON file contains:

```json
{
  "metadata": {
    "created_date": "2024-08-12T14:30:00",
    "total_records": 5,
    "format_version": "1.0"
  },
  "records": [
    {
      "ptid": "PTID001",
      "redcap_event_name": "baseline_arm_1",
      "nacc_upload_by_initals": "ABC",
      "nacc_upload_date": "2024-08-12",
      "nacc_upload_status_complete": "1",
      "nacc_reupload_date": "",
      "nacc_reupload_date_2": ""
    }
  ]
}
```

## REDCap Variables Updated

The following variables are updated for each PTID:

- `ptid`: Participant ID (record identifier)
- `redcap_event_name`: REDCap event name
- `nacc_upload_by_initals`: Initials of person performing upload
- `nacc_upload_date`: Date of upload (YYYY-MM-DD format)
- `nacc_upload_status_complete`: Set to "1" when upload completes
- `nacc_reupload_date`: Date of reupload (if applicable)
- `nacc_reupload_date_2`: Date of second reupload (if applicable)

## Usage

These files are consumed by the REDCap upload process to update status variables after successful Flywheel uploads.

The upload process is currently in development.
